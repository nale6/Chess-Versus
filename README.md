# Chess Versus

A web-based educational chess website built with React, Typescript and Vite, styled with Tailwind CSS. The app integrates Stockfish API to face against an AI opponent with adjustable difficulty,
and uses Firebase for real-time backend services for online multiplayer chess matches. Built with a focus on responsive design, with elements inspired by modern chess websites, without ripping
assets.

Deployed with Vercel on https://chessversus.vercel.app/
